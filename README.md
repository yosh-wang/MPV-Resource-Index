## 📌 关于本仓库

本仓库是为国内 MPV 爱好者建立的资源索引站，初衷很简单：

- 国内关于 MPV 的论坛和讨论区太少，大家遇到问题交流不便
- 很多新手不熟悉 GitHub 或英文，上手门槛太高
- 希望为中文用户提供**互助、分享、共同进步**的空间

所有整理的内容均注明原作者并附上 GitHub 仓库链接，尊重每位开发者的劳动成果。
